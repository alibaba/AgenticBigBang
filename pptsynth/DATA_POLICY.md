# Data policy

PPTSynth is distributed as a code-only snapshot. The release contains source
code, prompts, schemas, taxonomy configuration, documentation, and offline
tests only. It does not contain source PDFs, datasets, generated tasks or
rubrics, model responses, execution logs, caches, private adapters, or
organization-specific information.

## Before processing or publishing data

1. Confirm that you may collect, process, transmit, and redistribute the input
   under applicable law, contract, license, privacy requirements, and policy.
2. Do not submit credentials, personal data, proprietary documents, customer
   content, internal paths, signed URLs, or confidential source code to a model
   provider unless you are authorized to do so.
3. Treat every output directory as sensitive until reviewed: it can contain a
   copied PDF, extracted facts, model output, prompts, routing metadata, command
   diagnostics, and filesystem paths.
4. Publish data only after a separate review of provenance, inclusion criteria,
   transformations, permissions, and license. Provide a dataset card and
   checksums for any future data release.

The taxonomy and prompts are not a released dataset and should not be read as
claims about any particular organization, customer, or document collection.
