## 2. 内容约束

* **忠实于背景材料**：仅使用论文中的信息。不得捏造额外实验或修改、重新解读作者的论断。
* **准确性：**所有内容必须事实准确，尤其是定量内容和事实数据。
* **简洁性：**使用简短精炼的短语，而非长段落。聚焦于总结关键事实和要点，避免过度细节。可使用要点符号使内容更清晰。如使用要点符号，每页幻灯片不应超过6个要点。
* **充分深度**：不要以过于笼统或高层次的方式概括论文。幻灯片应保留必要的技术细节、关键论点和实质性发现，而非仅呈现模糊的结论。
* **逻辑流畅性：**幻灯片应呈现清晰的叙事脉络，每个章节自然地承接上一章节。确保从研究动机、方法论到结果和结论之间有清晰的递进关系。
* **信息相关性**：不得添加无关内容。
* **代码和标记格式**：除非必要，避免使用原始 LaTeX 或 Markdown 代码。
* **引用与出处标注**：准确引用论文的结果、图表和示例。
   * 如果幻灯片使用了论文中的数据，必须在该页幻灯片上清楚标注数据来源（例如，第xx页、图xx、表xx）。
   * 所有参考文献（如有）必须放在幻灯片左下角。

## 3. 视觉与设计

* **图片：**包含相关图片。图片必须高质量、标注清晰且与内容相关。
* **图表和示意图：**在需要的地方使用恰当的图表和示意图来直观呈现和阐释信息，而非仅依赖文字（和演示）。
  * 如果幻灯片包含图表或图形，确保所有视觉元素标注清晰（例如，坐标轴有标签、标明单位、需要时包含图例、必要时解释数据点）。
  * 在适当时包含**图形或示意图说明**，例如"该图（来自论文第4页）显示了不同处理条件下的实验结果对比。"
* **可读性：**使用清晰可读的字体，避免杂乱。文字应足够大，便于阅读。
* **视觉平衡：**平衡文字和视觉元素，确保投影时易于阅读。
* **布局：**保持简洁、专业的布局，使用合适的字体、颜色和格式。
* **风格一致性**：整套幻灯片应遵循统一、连贯的视觉风格。
* **信息密度**：每页幻灯片应避免信息过载，以保持可读性。

## 4. 文本质量

* 所有生成的文本应清晰明了，不得有缺失或错误的字符或词语。
* 拼写、语法和排版必须准确无误。

## 5. 技术忠实性要求

* **定量覆盖**：确保论文中的关键数据和实验结果（可能在论文的图表中呈现）包含在幻灯片中。换言之，报告不应仅讨论论文的思路，还应呈现具体的定量细节（例如统计数据、实验结果等）。
   * 如论文包含定量实验结果或数值分析，幻灯片必须包含至少5页含有定量细节的页面。如论文为定性研究（历史述论、政策分析、综述等），则要求至少5页包含具体论据支撑（引文、案例、数据引用或逻辑推导）的分析页面。

* **定量细节准确性**：确保定量细节（实验计数、样本量、基准规模等）准确无误。

* **图表可追溯性与标注**：确保幻灯片中的任何图表与论文一致。具体而言，对于幻灯片中的每个图和表：
  * 如果直接复制自论文，须在幻灯片上清楚标注其对应论文中的哪个图或表（例如，论文图1、论文表2）。
  * 如果是根据论文数据重新绘制的，须清楚标明数据取自论文的哪个章节（例如，第3.1节）。此外，须清晰解释图中每个图例项和表中每行每列的含义。
  * 对于图表，每个坐标轴、单位和标签必须明确标注。

* **图表点级精度**：如果幻灯片中使用了散点图、折线图或雷达图，确保每个数据点与论文原图中的对应数据点完全一致。注意，数值必须**精确**相同，而非仅图形形状相似。

* **概念性示意**：幻灯片可包含仅用于概念说明的数据。但如果包含此类数据，必须在相应幻灯片上清楚标注哪些数据是概念性示意而非论文中报告的实验数据。

## 6. 演示风格与听众

* **语气：**语气应为学术性的、专业的和信息丰富的。应避免随意或非正式的对话语言，同时保持清晰、适合口头报告。整套幻灯片应保持一致的语气风格。
* **听众：**报告面向具有相关领域背景知识的学术听众。内容应适合研究生及研究人员理解，假定听众熟悉标准概念和术语，同时仍提供足够的上下文以理解研究动机、方法论和关键贡献。
